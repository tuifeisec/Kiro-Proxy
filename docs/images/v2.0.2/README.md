# v2.0.2 配图来源

本目录服务于项目首页与 v2.0.2 Release 的图文介绍。

- `cover.svg`：版本与产品能力封面，为编辑图形，不是软件界面截图。
- `dashboard.png`：仪表盘。
- `models.png`：模型管理页。
- `auto-routing.png`：已配置示例目标的 Auto 职责设置。
- `requests.png`：请求统计页，包含 6 次本地模拟请求。
- `inspector.png`：实时流量日志及一条本地示例请求的 JSON 详情。

截图来自已发布的 v2.0.2 Windows x64 桌面二进制，通过其内嵌前端拍摄。构建源码为 `5684805eab0997e587c56a2e2223cfee252fc55d`，二进制 SHA256 为 `0aaa0c2c57b2c8fb6f7b2d30610f9f6ce91b2666cb70ede6599ed430c2016c47`。

拍摄使用独立临时数据目录和回环端口，不读取或修改开发目录中的数据库与证书。模型名、ID、密钥占位值、价格均为演示配置；请求通过本地模拟上游生成，未调用真实供应商。数据用于说明字段与界面，不用于证明真实服务兼容性、性能或费用。演示实例没有安装系统 CA，也没有执行 Kiro 代理配置或重启操作。

图片没有拼接或替换界面内容。对话框截图等待动画结束后拍摄；封面为独立 SVG。后续功能界面变化时，应重新从对应版本拍摄，不将旧截图标为新版本。
